## 首轮线上测试

- 保留现有 private_only 三中心开发划分；train 1148、val 164、internal_test 328、怀柔 external_test 485。转换后不改变图像或实例划分，不合并测试集。
- 两种模型均采用53类、COCO预训练、24 epoch、imgsz=960（方形）、batch=4、seed=42、AMP，关闭左右/上下翻转、颜色扰动和几何增强。训练前先验证实际GPU及前向/反向显存。
- AdamW：YOLO11m 初始学习率0.001，RT-DETR-L为0.0001。采用不同学习率是模型配方级比较，不是严格控制所有训练变量的架构因果比较。
- 与旧 Faster R-CNN 的初始化（ImageNet backbone）、输入（1600x960等比例）、优化器和checkpoint选择方式不同；不能把结果差异全部归于架构。
- 先YOLO11m后RT-DETR-L，分别独立进程，训练后依次评估val/internal_test/external_test。用原COCO坐标和类别ID计算COCO指标，再用统一的一对一类无关匹配评估候选召回。best.pt仅依据训练期间验证集指标选择。
- 低阈值预测conf=0.01、YOLO NMS IoU=0.6、候选上限500；RT-DETR实际输出受查询数量约束，需如实记录，不宣称候选上限等价。普通COCO评估沿用默认maxDets=100，候选分析另统计全部保留框。
- 只保留last和best权重，所有数据转换、日志、模型、评估结果位于 `/root/autodl-tmp`。预测PKL仅有框、标签、分数等，暂未实现新检测器的RoI特征或完整类别概率导出，不冒充与Faster R-CNN完全相同的Agent接口。

## 本地接口验证

工具 `tools/analysis_tools/validate_dental_interface.py` 已对14份已有预测运行。比较IoU=0.75/0.85/0.95的几何分组，每组最高分框为代表；所有原始候选索引保留，类别不确定性以该代表的top-3类别概率表达。无学习、无新推理；几何归并仅为接口原型，不代表已辨认物理牙齿实体。

以下是三中心baseline、怀柔测试、IoU≥0.5匹配结果。原始预测score≥0.01；主层定义score≥0.1，其他组为复核层。

| 展示策略 | 平均框/组数 | 多生牙框匹配 |
|---|---:|---:|
| 原始低阈值候选 | 86.3 | 44/53 |
| IoU≥0.85归并，主层+复核层代表 | 72.0 | 44/53 |
| IoU≥0.85归并，仅主层 | 47.6 | 33/53 |
| IoU≥0.75归并，全部代表 | 61.7 | 43/53 |

0.85归并后的平均复核层为24.4组。相同策略在val上将70.5个原始候选降至63.5组，多生牙仍为9/10。完整输出是 `records/remote_runs/20261029_private_frcnn_matrix/interface_validation.json`，结构样例是 `interface_preview.json`。

解释：接口减负有效但有限。0.85只减少约16.5%的默认低阈值框；提高合并强度开始损失多生牙。主层虽接近正常牙列数量，但会隐藏部分多生牙，必须保留可查询的复核层。所有组的原始框与特征仍存在原始PKL中，原始引用的可恢复性不等于代表框召回无损。平均框数下降不是后端推理准确率提高的证据；本轮未运行Agent或医生可用性评估。

不得利用外部测试选择阈值。上述外部结果只是固定网格的描述性复盘，后续策略选择只依据验证集；当前外部集已被反复分析，发表时应说明其使用过程并争取独立确认集。

## 模型设计分阶段计划

主设计选择：先在单个Faster R-CNN内部实现解耦，不增加第二个检测模型或模型融合。YOLO11与RT-DETR作为后续架构对照，不以新架构本身作为论文创新。

### 对照与实现顺序

| 编号 | 单模型设计 | 要回答的问题 |
|---|---|---|
| D0 | 当前53类Faster R-CNN | 已有基准，无需重复训练 |
| D1 | 同配置单类Tooth检测 | 移除编号分类后，候选召回/冗余是否改善 |
| D2 | 共享特征：存在性头+53类身份辅助头+类无关回归 | 能否在保留编号证据的同时，不让编号置信度决定实体保留 |
| D3 | D2加学习型同牙关系及可逆实体分组 | 能否减少重复实体而不合并不同牙齿 |

D2中，RPN仍生成候选；RoI分支分别输出牙齿存在性概率、类无关坐标和身份概率。存在性使用全部已标注牙齿（含extra_tooth）作为正样本，背景为负样本；FDI/extra身份头只在正样本上训练。候选排序和保留使用存在性分数，身份低置信度仅产生待复核标记，不直接删框。总损失可写为 L_RPN + L_presence + L_box + lambda_id * L_identity；先固定其余权重，验证lambda_id=0.25/0.5/1的影响，不预设最佳值。D1与D2应明确区分，避免把“单类检测”与“保留辅助编号”混为一谈。

模型不存在“未知高密度影就是多生牙”的规则。身份高熵可以触发复核，但不构成多生牙诊断；存在性高分也可能是正常牙重复候选或伪影。

每次模型改动都同时比较原始候选与相同固定接口，不一边换模型一边换合并规则。主评价是固定候选预算/未匹配候选水平下的全牙与多生牙召回，并报告严格IoU定位质量。参数选择只用val；目前val多生牙样本很少，应同时给匹配数和真值数，不能用小数点后的变化认定稳定收益。最终对有效设计补多种子与按图像聚类的不确定性估计；缺乏患者ID时，不宣称患者级统计独立。

### 接口约束

每个暂定实体包含一个主框、原图尺寸与坐标约定、存在性/检测分数、FDI候选概率及原始候选引用。暂定几何组明确带有provisional标记，不直接声称是已确认的一颗牙。主层供默认浏览，复核层必须可查询；不以强制固定牙齿数或全局top-K直接丢弃多生牙。原始框、不同坐标假设及视觉特征保留在证据层。应另外评估复核组数量、后端查询负担与误合并，而不是仅报告“JSON条目少了”。

### 后续扩展

1. **任务解耦对照**：在选定架构内配对训练53类和1类Tooth。先包含Faster R-CNN单类对照，避免把标签合并收益误归于换模型。存在性检出与FDI正确识别分开评估。
2. **单模型双任务头**：共享backbone，候选生成/回归以牙齿实体为目标；存在性分支和FDI辅助分类分支分开，保留FDI概率，不通过FDI唯一类别硬筛除未知牙齿。研究class-agnostic回归，必须与标准class-specific回归消融，不假定一定更准。
3. **学习型重复关系**：使用候选几何、局部视觉及类别分布判断两框是否同一颗牙。用训练集GT匹配生成同牙/异牙配对，忽略匹配模糊样本；验证时重点检查乳牙与恒牙胚、紧邻及多生牙。保留可逆分组，避免传递式合并将相邻牙串成一个实体。
4. **定位监督**：先分析严格IoU下的误差和牙根吸收案例，再决定是否增加中心/冠部辅助任务。无真实冠部标注时不能宣称牙冠监督；固定上下方向只是弱先验，异位牙/多生牙不强制套用。

核心比较必须同时报告全牙及多生牙框召回（IoU≥0.5和0.75）、候选/实体数量、未匹配候选数、归并后召回损失和多牙误合并率。后续补充阈值曲线、置信区间及多种子；本轮没有完成这些统计验证。Agent仍后置，不靠其补救完全漏检。
