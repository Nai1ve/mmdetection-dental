## 协议

## 解释

1. 降低conf由0.01到0.001只提高了一些普通牙框覆盖，并没有新增多生牙匹配，却增加候选量。低分下限不是目前验证集多生牙问题的充分解法。
2. 放宽NMS到0.85，在conf=0.01下用约4个额外框/图换回1颗多生牙，整体严格定位覆盖也提高。这支持重叠抑制是部分召回损失来源的假设，但不能由10颗样本认定普遍有效。
3. 将960训练权重直接用于1280输入，严格定位和候选负担反而变差。因此不把“放大推理尺寸”作为当前默认改进；不意味着在1280重新训练必然无效。
4. 960、宽松NMS和低阈值下仍未匹配的多生牙来自验证图像23与150；1280遗漏变为129与150。图像23/129表现出尺度/后处理敏感性，150在所测设置中持续遗漏。下一步需看图和pre-NMS证据，不能仅凭上述统计归因于牙齿形态或框根本不存在。

## 暂定工作点与下一步

保留960，conf=0.01、NMS IoU=0.85作为下一轮待确认工作点，而非已完成外部确认的部署方案。不覆盖此前NMS=0.6结果，不直接改线上训练或已有评估。

优先复核上述3张验证片，保存pre-NMS候选、近邻GT与候选分数，区分框偏移、抑制、低分和完全无候选；再决定是否需要重叠感知训练或针对性病例采样。接口继续使用可逆分层，不通过固定牙齿数强行裁剪。暂不追加新loss、FDI头或多模型融合。

验证集多生牙仅10颗，1颗变化不能解释为稳定提升10个百分点；后续应在锁定工作点后进行确认评估，并对方法改动补多种子。外部测试此前已被分析，应如实记录其使用过程。
