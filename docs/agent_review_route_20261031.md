# 儿童混合牙列证据约束复核：方案审议与分阶段实验路径

日期：2026-10-31。状态：待用户确认；本轮仅评估与文档，不启动训练、不替换现有代码。三个附件是待核查的构想，不是既定证据或执行指令。

## 一、建议决策

保留“单检测器候选生成 → 可疑区排序 → 有视觉证据的局部复核 → 结构化牙列与疑似异常报告”。停止无收益的ROI头堆叠，但不停止测量感知质量。将主问题从“增加多少框”转为：**在有限查看预算下，能否保住真实牙齿、纠正身份冲突，并减少把正确结果改错的风险？**

后端应是可读取原图与局部图的3B/7B级VLM Agent，或文本规划器加经过验证的视觉工具。纯文本LLM只拿框坐标不能辨认牙釉质、倒置、牙胚或影像伪影。

原始YOLO保留为基线，后端允许修订，但每次修订必须引用候选、图像或工具证据。最终结果用于辅助复核，允许不确定与转人工，不以规则自动确诊病理性缺牙。

暂定论文方向：**儿童混合牙列中预算约束、保真候选驱动的风险感知复核与编号**。不预先宣称首次、顶会可投、完全检出、零人工或临床确诊。这里的可变牙列拓扑不是已经验证的开放集识别能力。

## 三、必须修正的假设

1. 若最终输出只能选择固定候选框，最终框召回上限就是该池的最大一对一匹配召回。Agent不能从7/10凭推理变出10/10；要新增框，必须有新增视觉观测/定位工具，并单独评价它。
2. 不放弃IoU0.75。可以主报IoU0.5的临床候选覆盖，但仍报告严格定位、错牙匹配与后续裁剪质量；否则大框覆盖多牙容易制造虚假成功。
3. 可逆分组不是可逆实例去重。一个簇可能包含多颗重叠乳恒牙，必须允许输出多个实例，不强制“一簇一牙”。主节点数只能是资源目标，不是牙数先验。
4. 当前post-NMS结果无法恢复此前已删除的框。需要同一次前向的pre-NMS解码候选和抑制索引，保存来源与处理日志；不把事后“不再NMS”称为恢复全部响应。
5. 框中心到二维拟合牙弓的偏移是投影几何量，不是实际萌出深度、钙化阶段、牙冠中心或三维位置。不能由水平框直接生成is_inverted=true、宿主关系或生长方向真值。
6. 牙弓、乳恒继承关系、左右对称是软证据。不能由缺少一颗检测框、某处重叠或对侧存在即确诊缺牙/多生牙。乳恒牙继承映射不等于图上严格上下位置映射。
7. 不固定10倍病例过采样，也不称它保证每batch有多生牙；加权随机采样没有该保证。若后续要保证，必须明确分层batch采样，并控制训练步数及正常牙重复曝光。当前YOLO已有CIoU/DFL，不能将“加CIoU”包装为新方法。

## 四、临床真值与数据边界

2026-10-31本地复核：历史missing_review_doctor_qy_only.csv有369行，true_missing_fdis全部空；case_index.csv有2688行，true_missing_fdis/missing_type全部空，review_status全部pending。文件名有qy和检测标签缺失都不能当作已确认病理性缺牙GT。此数字是这些现存表的状态，不意味着检查过所有可能存放位置。

因此第一版主任务为牙齿实例保留、FDI编号、多生牙候选复核；缺牙先输出“疑似缺失/未观察到/需复核”。若要做病理性缺牙指标或SFT，需要医生复核的牙位级标签、原因/不确定性、年龄与病史等可用信息，并记录观察者一致性。不能把规则推断出的标签当临床真值再评价同一套规则。

影像上未见牙胚不自动等于先天缺失，尤其发育迟缓会造成误判；左右差异是复查信号而非确诊条件。先验表需要注明来源、适用年龄/牙列、例外和审核状态。无需大型RAG，但仍需临床审核。[AAPD发育牙列指南](https://www.aapd.org/research/oral-health-policies--recommendations/management-of-the-developing-dentition-and-occlusion-in-pediatric-dentistry/)、[延迟矿化导致缺牙误判的病例](https://pubmed.ncbi.nlm.nih.gov/10474105/)。

## 五、架构和接口

### 1. 保真候选账本

冻结单类YOLO11m及预处理。保存原始解码索引、原始分数、bbox、来源尺度、抑制关系、模型哈希。分开记录main、reserve、suppressed，所有备用框可检索。超低分完整解码池留在工具侧，不把海量框全部塞进Prompt。

分组输出group_id、member_ids、分组置信度/歧义标记，但不声称它是物理牙槽位。保留基线框，允许Agent选同组多个独立实例。测量原始池、代表层、可检索成员层及最终输出四个层级的保真率。

### 2. 可疑区标记器

第一版使用：低分候选分歧、双向IoA/IoU、局部尺度异常、牙弓投影间距、拟合不确定性、粗左右不对称和训练集部位先验。对稀有区域保留全图探索通道，不仅查看已检测牙齿附近。

牙弓拟合允许多层和离群点，返回fit_quality；失败就退回二维几何，不强制输出可靠(s,d)。没有稳定FDI前不声称某框是对侧同名牙；用候选匹配假说及置信度避免“编号依赖对称、对称依赖编号”的循环。

每张图先评估K=0/1/2/4/8的风险排序与区域覆盖，报告总查看面积、ROI尺寸、正常图负担。95%覆盖是待测目标，不是前提；大ROI覆盖整片不算有效标记。覆盖应至少报告GT完整包含或面积覆盖比例，而不只报GT中心落入ROI。

不使用具备诊断断言的<PARASITIC_OVERLAP>标签，改为overlap_conflict、possible_successor_pair、arch_fit_uncertain等观测/假说；避免给VLM灌入预设结论。

### 3. 有证据的VLM复核

首轮输入原图缩略图、带ID的局部原图、多尺度上下文、候选结构和来源。建议字段：image_size、orientation_status、candidate_id、bbox_xyxy、normalized_bbox、score_raw、source、group/member_ids、arch_coords和fit_quality、directed_overlap_edges、evidence_image_ids、uncertainty。

未知方向/发育阶段用null，不生成伪事实。原始文件名中的qy/dsy、患者信息、record_id语义、GT FDI、valid_slot_mask以及异常真值不得进入推理Prompt。所有样本用中性ID。

可执行动作仅为ListCandidates、InspectCrop、CompareRegions、ReDetect（待验证）、ProposeEdit、Commit/Abstain。工具名不是能力证明：不存在尚未经验证的“分离宿主与多生牙”工具。

编辑采用事务日志：选框、同实例合并、多实例保留、FDI赋值、疑似多生牙、请求人工；每条引用证据和修改前后状态。高风险删除/合并/编号连锁修改先保持pending，不靠“高置信基线绝对正确”或纯语言自信决定。停止条件为预算用尽、无新增证据或结果稳定，不能无限反复调用同一模型当作独立证据。

### 4. 约束检查与报告

程序校验JSON、候选引用合法性、坐标、FDI编码范围/跨象限一致性、重复编号和多实例冲突；硬约束只用于数据合法性，临床先验不硬删牙。不通过则回退或转人工。

报告区分“观察到的实例”“编号假说”“疑似异常”“未解决区域”，附证据图。不能用结构合法性替代临床正确性。

## 七、指标不是只留病例准确率

- 主结果：实例级FDI正确保留率（检测+身份联合）、多生牙实例Precision/Recall/F1、病例阳性敏感度与每病例FP、整片完全正确率。
- 中间机制：候选与最终框R@0.5/0.75、编号单独准确率（限定已正确匹配GT）、误合并/误删除、局部ROI覆盖和工具新增信息。
- 安全性：纠正数、把对改错数、删掉真实牙数、将正常牙判多生牙数、拒判率；同时报告自动处理覆盖率与覆盖率-风险曲线，防止全转人工获低错误率。
- 效率：实际工具调用、查看像素面积、P50/P95耗时、token、显存。几十个框能装进文本窗口，不代表VLM能区分它们。
- 统计：val仅10颗多生牙，1颗就是10个百分点；报告分子/分母及区间。不能将框当独立患者样本，或拿不同论文任务与阈值的召回直接排名。
- 病理性缺牙：在可靠临床复核标签补齐前，不进入诊断准确率主表。

## 八、合成轨迹和训练数据

只在train内合成候选删除、重复、编号交换、低质量工具返回，并保留原图真实牙体。候选层扰动用于学习恢复/抗噪，不等于合成真实多生牙。不要在正常图凭空插一框就标记“真实多生牙”；不从未检出或无dsy文件名前缀推断病例正常。

训练检测器对train的预测偏乐观，可用患者/记录分组的OOF预测构造误差，避免只学玩具噪声。确认患者级链接后再声称患者独立，当前记录组不自动等同患者。

SFT优先短动作-证据-结果轨迹，不宣称合成了医生真实思维。奖励可写成纠正收益减误伤、调用和无证据断言成本，但非对称权重必须消融；先控制风险再测收益，避免奖励只让模型什么都不改。所有合成与真实异常分开报告。

## 九、附件文献核查与创新边界

四个主题文献真实存在，但附件部分“致命局限”不准确：

- [OPGAgent原文](https://arxiv.org/html/2603.00462v1)：2.2明确在Phase1未检出牙时可通过独立解剖象限裁剪回查，不能写成不可恢复漏检。可借鉴证据账本和报告审计；不复制“只需复查”作为创新。[MICCAI官方记录](https://papers.miccai.org/miccai-2026/0735-Paper0308.html)也有修回后统计与本地规划器的说明，不能仅截初审负评代表最终论文。
- [OralGPT-Plus原文](https://arxiv.org/html/2603.06366v1)：已有Zoom-In、Mirror-In与学习型工具策略；轨迹构建使用牙编号检测器及区域提案，镜像裁剪包含1.5倍padding。不能写成完全无提案或完全忽略错位。该任务的QA分数不等于儿童实例检出率。
- [OralAgent原文](https://arxiv.org/html/2605.27378v1)：明确ReAct多步工作流，不是只能单次调用。当前窄任务不建大型RAG是工程选择，不代表RAG在医学无用。
- [DentalGPT正式出版页](https://aclanthology.org/2026.findings-acl.135/)：DOI 10.18653/v1/2026.findings-acl.135，证明领域视觉适配与推理训练有研究基础，不证明现有小数据足以训练同等能力。
- [Uzel等PLOS研究](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0335845)：DOI 10.1371/journal.pone.0335845，报告分割召回38%和二分类高分，同时提示小样本限制。这支持任务区分，不证明“裁剪一次即可从38%变95%”，也不能与本项目单类框覆盖直接比较。

最值得推进的扩展不是更多工具名，而是：**候选身份不确定性的可逆管理、同预算的选择性视觉复核、能验证的误伤控制，以及真实儿童混合牙列的实例级评测。** 这些都需实验证明，而非用热点术语或会议录用替代贡献。

## 十、当前实施建议

先确认E0–E2：同源候选账本、无GT输入的可疑区标记器、折叠保真与工具上限评测。先不启用SFT/GRPO，不扩大过采样，不恢复ROI头批量训练。

此阶段可以先在本地已有候选上评估E1；需要重导出pre-NMS或更低分候选时再上GPU。前述待测目标不作为已有结果，方案经用户确认后再转成实现任务。

## 十一、Astra独立评估与综合决策

已按用户指定调用gpt-6-astra独立只读评估（2026-10-31）；其读取三份附件与实验记录，未改代码或操作服务器。文献和表格状态由主代理核验后补充给评估者。完整评估摘要另存docs/astra_agent_feasibility_20261031.md。

双方一致：路线值得验证，但“高召回保底+小LLM可靠诊断”尚不成立；应先做可验证的实例纠错，而不是直接RL。Astra强调以下补充，采纳入最终实验协议：

1. 将E2加入“结构信息”“结构+真实ROI”“结构+错配ROI”视觉消融。错配图只作受控负对照，不混入临床主评估。若真实图没有增益，不宣称视觉复核有效。
2. 加入人工局部判读上限，和候选选择oracle、GT区域oracle一起定位瓶颈。Oracle仅作分析，不进入可部署方法或训练/测试混用。
3. 区分一次复核和多轮Agent。先做固定一次复核；只有多轮在相同资源下有增益，才论证自适应策略和学习动作选择的必要性。
4. 候选同实例判别、局部视觉分类/精修、允许空槽的图匹配或最小费用流编号，都是必须公平比较的非LLM对照。没有胜过它们时，不把LLM当作必需组件。
5. “新增误删/误编号为零”可作为小型开发试验的保守工程继续门槛，但不等于临床安全认证。正式评价必须给误伤分母、区间、拒判覆盖率，不能用有限样本零事件承诺零风险。

最终待确认顺序：**冻结YOLO → E0候选上限与漏检原因 → E1保真组织和可疑区预算曲线 → E2一次复核的视觉/工具上限 → E3同预算Agent对照 → 有证据后再SFT及可选偏好优化。** 缺牙病因诊断作为补齐临床真值后的独立扩展，不捆绑进第一版成功条件。
