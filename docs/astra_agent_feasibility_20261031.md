# Astra独立可行性评估摘要

日期：2026-10-31。评估模型：gpt-6-astra，按用户明确指定调用。只读三份附件与既有实验记录；文献核查和缺牙表状态由主代理补充，不是评估者独立复核过全部论文。未改代码、未启动训练。

## 评估结论

值得做“预算受限、证据可追溯的牙列纠错”；目前不足以支持“高召回保底＋小VLM即可可靠诊断”，不宜直接进入RL。几何先验用于分配注意力，而不是裁定牙数异常。

## 核心风险

- conf0.001不是保障：历史难例粗框分数低至0.000509/0.000168，且有跨牙NMS抑制。应审计抑制前候选。
- 35–45主簇是可展开展示层，不是实例上限；一簇可能多牙，保存在文件不等于模型会访问，成员展开有成本。
- 三个信息关口：目标是否进入候选、候选能否由图像区分、正确候选能否被保留并编号。纯坐标不提供新的患者特异视觉证据；允许VLM新造框就引入了新定位器，需独立评测。
- 既有裁剪与旋转无多生牙增益；四槽并集粗框增加不证明可用。重复率降低或槽位匹配看似均衡，也不能单独证明实例分工。
- 附件对既有工作的部分局限描述错误，不可用来证明首次创新。95%覆盖、秒级、零冗余都是待测目标。

## 建议最小验证

1. 建失败账本与oracle：池内理想选择、完整成员、GT指定ROI/人工判读上限。若既定预算连oracle都无收益空间，则停止该工具路线。
2. 先测ROI选择：K=1/2/4并限制像素、候选读取和工具调用，对照规则、固定区域、均匀区域及oracle；不能用巨型区域中心命中制造覆盖。
3. 验证一次复核净收益：规则、轻量视觉模型、小VLM使用相同证据；统计补回、误删、误加与编号连锁错误。真实ROI与错配ROI作视觉负对照。
4. 有收益后再训练：SFT先学有证据的操作及拒绝操作；多轮先赢过一次复核，才考虑偏好优化。DPO/GRPO不是必经流水线。

## 竞争基线与扩展

必须包括候选对同实例判别器、局部视觉分类/框精修、图匹配或最小费用流编号、同预算固定复查。最有价值扩展是可逆编辑与选择性拒答：每条改动绑定候选ID、证据ROI和撤销记录。

若规则或小视觉模型胜出，也应保留真实结论，不为Agent叙事跳过对照。

## 统计与临床边界

74颗训练多生牙来自67图，不能把扩充ROI/轨迹当成新增独立阳性病例。val仅10颗，7/10和9/10的区间很宽，而且9/10只是粗框并集结果。需病例配对分析、患者级分组和聚类bootstrap，额外报告FP/图、病例异常检出、整片无错率与误伤。

旧缺牙表真值空、复核待办，不能构建病理性缺牙监督或诊断评价；未检出与病理性缺牙必须分开。合成噪声可训练工具语法/已标注任务，不能补造临床真值。反复查看的外部集应标探索性，强确认需新中心或时间留出。

## 推荐核心假说

在混合牙列全景片中，相比同预算固定复查与非LLM结构化基线，可逆候选表示和证据驱动的区域复核，能否在不增加误删、误编号及假阳性负担的条件下，提高牙列实例重构的病例级正确率？

把小VLM、多轮、RL是否必要作为递进消融，不预设结论。此摘要为Astra评估的压缩整理，最终综合方案见docs/agent_review_route_20261031.md。
